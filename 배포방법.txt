롱숏 스크리너 (폰 설치용 웹앱) 배포 방법
=====================================

이 폴더의 파일 6개(index.html, manifest.webmanifest, sw.js, 아이콘 3개)를
인터넷 주소(https)에 올리면 폰에서 앱처럼 설치해서 쓸 수 있어요.
서버나 API 키는 필요 없어요. 폰 브라우저가 OKX에서 직접 시세를 받아요.

[방법 1] Netlify Drop (가장 쉬움, 계정 없이 시도 가능)
  1. 이 폴더 압축을 풀어요.
  2. 브라우저에서 https://app.netlify.com/drop 을 열어요.
  3. 압축 푼 폴더를 화면에 끌어다 놓아요.
  4. 나온 주소(https://xxxx.netlify.app)를 폰에서 열어요.
     (계정 없이 올린 사이트는 잠시 뒤 사라질 수 있으니, 계속 쓰려면 무료 가입하세요.)

[방법 2] GitHub Pages (무료, 주소가 계속 유지됨)
  1. github.com 에서 새 저장소를 만들어요 (Public).
  2. "Add file > Upload files" 로 파일 6개를 올려요.
  3. Settings > Pages > Branch: main / (root) > Save.
  4. 1~2분 뒤 https://내아이디.github.io/저장소이름/ 주소가 열려요.

폰에 설치하기
  - 안드로이드(Chrome): 주소를 열고 메뉴(점 3개) > "홈 화면에 추가" 또는 "앱 설치".
  - 아이폰(Safari): 공유 버튼 > "홈 화면에 추가".

처음 실행했는데 "스캔에 실패했어요"가 뜨면
  - 인터넷 연결을 확인하고 "다시 시도"를 눌러 보세요.
  - 계속 안 되면 OKX가 브라우저의 직접 요청을 막은 거예요. 설정의
    "OKX API 주소"에 중계 서버 주소를 넣어야 해요. (만들어 달라고 요청하세요)

참고
  - 앱을 열어 둔 동안에만 갱신되고 알림이 울려요. 백그라운드에서는 폰이 앱을 멈춰요.
  - 이 앱에는 개인 정보나 API 키가 들어 있지 않아요. 설정은 폰 안에만 저장돼요.
  - 투자 조언이 아니에요. 진입가·손절·목표는 참고 값이고 수수료/슬리피지는 반영하지 않았어요.
